# ژورنال طلا 🪙

برنامه‌ی ثبت ژورنال معاملات طلا (XAUUSD): واریز، برداشت، سود و ضرر هر معامله و دلیل ورود و خروج.

- سه حساب جدا: اصلی، پراپ، دمو (با فیلتر و آمار جدا برای هرکدوم)
- خلاصه‌ی زنده: سود/ضرر خالص، مجموع واریز و برداشت، جریان خالص، وین‌ریت، میانگین سود و ضرر
- آفلاین و بدون سرور — همه‌چیز روی خود گوشی ذخیره می‌شه (localStorage)
